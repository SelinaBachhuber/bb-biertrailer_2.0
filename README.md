# BB Biertrailer

Welcome to the BB Biertrailer project! This repository contains the source code for a modern and professional website dedicated to showcasing our beer trailer rental services.

## Overview

BB Biertrailer offers a unique experience for events and gatherings with our high-quality beer trailers. Our website provides information about our products, services, and how to get in touch with us.

## Features

- **Responsive Design**: The website is fully responsive and works seamlessly on all devices.
- **About Page**: Learn more about our company and mission.
- **Contact Page**: Get in touch with us through our contact form.
- **Gallery**: View images of our beer trailers in action.
- **Products**: Explore the various beer trailers available for rental.
- **Services**: Discover the services we offer alongside our rentals.

## Installation

To get started with the BB Biertrailer project, follow these steps:

1. Clone the repository:
   ```
   git clone https://github.com/yourusername/bb-biertrailer.git
   ```
2. Navigate to the project directory:
   ```
   cd bb-biertrailer
   ```
3. Install the dependencies:
   ```
   npm install
   ```

## Usage

To run the development server, use the following command:
```
npm run dev
```
Open your browser and navigate to `http://localhost:3000` to view the website.
